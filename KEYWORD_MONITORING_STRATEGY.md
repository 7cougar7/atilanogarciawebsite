## Keyword Monitoring Tools

### Free Tools
1. **Google Search Console** (Primary)
   - Monitor search queries bringing traffic
   - Track average position for target keywords
   - Identify new keyword opportunities
   - Monitor click-through rates

2. **Google Analytics 4**
   - Track organic search traffic
   - Monitor keyword performance via Search Console integration
   - Analyze user behavior from different keywords

3. **Manual Tracking**
   - Weekly manual searches for primary keywords
   - Document position changes in spreadsheet
   - Monitor SERP features (featured snippets, knowledge panels)

### Paid Tools (Recommended for Advanced Monitoring)
1. **Ahrefs** - Comprehensive keyword tracking and competitor analysis
2. **SEMrush** - Keyword position tracking and SEO insights
3. **Moz Pro** - Keyword ranking and SERP feature tracking
4. **Ubersuggest** - Budget-friendly keyword tracking

## Integration with Google Search Console

### Key Metrics to Monitor:
- **Queries**: Which search terms bring traffic
- **Impressions**: How often you appear in search results
- **Clicks**: How many people click through
- **Average Position**: Your average ranking for each query
- **CTR**: Click-through rate for each query

### Weekly GSC Review Process:
1. Export performance data for last 28 days
2. Compare with previous period
3. Identify top-performing queries
4. Find high-impression, low-CTR opportunities
5. Update keyword tracking spreadsheet
6. Plan content optimizations
